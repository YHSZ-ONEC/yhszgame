🧭 界面与布局
  • 模式切换：右上角「🛠 工坊模式 / 🎞 GIF模式 / 🎨 画布模式 / 🤖 AI 拆分」四档互斥切换。
  • 侧栏面板可点标题折叠/展开（箭头 ▾ 指示），状态按模式独立记忆；侧栏顶部「▾ 全部收起 / ▸ 全部展开」一键整理。
  • 新功能会放在对应面板：素材处理类在工坊侧栏，绘制/帧类在画布右侧栏；找不到时用「⚙ 设置 → 📖 操作说明」搜索。
  • 布局已按常用流程收紧：工坊侧栏按「处理 → 缩放 → 动画 → 导出」排列；画布右侧栏按「色板 → 帧 → 绘制 → 选区 → 操作 → 导出 → 变换」排列。
  • 通用快捷键：Ctrl+Z 撤销当前模式上一步，Ctrl+Y / Ctrl+Shift+Z 重做；在输入框内保留浏览器原生文本撤销。
📥 上传 & 去背景
  • 上传图片后调「去背景容差」：值越小越精确、越大越宽松；「🎨 从画布模式导入」可直接把画布模式的当前帧作为参考图导入。
  • 背景模式「自动」：自动检测边缘纯色背景；「手动取色」：把背景模式切到「手动取色」后点「🎯 点击画布取背景色」，再点击画布上的背景色即可精确去除指定颜色。
  • 「边缘平滑」：去背景后对边缘做 1 像素柔化，减少锯齿（像素画建议关闭）。
  • 「收缩边缘」：去背景后向内收缩 1~10 像素，清除边缘残留的背景色/晕边（照片抠图建议 1~3px；想直接去掉指定背景色及其相近色，用「手动取色」+ 调大容差）。
  • 常用整理：「✂ 裁透明边」去掉四周空白透明区；「🎯 居中到目标尺寸」按像素化缩放里的目标宽高居中成统一画布。
  • 「👁 按住对比原图」临时显示原图，松开恢复处理图，适合检查去背景/缩放是否破坏轮廓。
  • 「↩ 还原去背景」可撤销本次去背景；「💾 保存状态」可存档当前画面，之后任意修改后点「↩ 还原到保存点」回到存档状态。
🔬 像素化缩放
  • 「🎮 像素画模式」：最近邻硬边缘，适合像素素材二次缩放。
  • 照片/高清图建议关闭像素画模式，用「边缘感知」算法 + 「照片增强预处理」(自动对比度/饱和度)，转像素效果更好。
  • 目标尺寸支持 1~2048，预设 64/128/256/512/1024；真实人物图可用 128~256 得到清晰像素小人。
  • 颜色量化 + Floyd-Steinberg 抖动可统一色数风格；边缘锐化强度可调。
🎞 GIF 模式
  • 导入 GIF/视频后选择抽帧策略：逐帧、固定间隔、场景变化或去重后保留；最大帧数和最大边长用于控制内存。
  • 智能去重使用 pHash/dHash 粗筛 + SSIM/MSE 复核；「保留非重复」「每 N 帧保留」「删未勾选」适合快速减帧。
  • 帧管理：Ctrl+点击切换勾选，Shift+点击范围勾选，Shift 拖框批量勾选，Ctrl+Shift 拖框批量取消。
  • 批量清洗：「去背景选中帧」使用工坊同款边缘背景检测 + 泛洪清除人物外部背景；手动吸管适合背景色不稳定的素材。
  • 统一缩放支持最近邻、面积平均、双线性和保持比例；导出支持精灵图+JSON、PNG序列ZIP、重组GIF、送到工坊/画布。
  • 预览区：滚轮缩放，中键按住拖拽平移；所有清洗、删除和选择操作支持 Ctrl+Z / Ctrl+Y。
🤖 AI 拆分 (骨骼)
  • 顶部「🤖 AI 拆分」进入拆分模式，工具在画布右侧展开。
  • 推荐流程：先点「⚡ 本地智能拆分」得到离线初稿；如果需要语义命名更准，再用「🤖 AI语义拆分」。AI 返回后会自动执行像素贴合。
  • 「🧲 贴合像素」会把 AI/手动画出的粗多边形收敛到当前帧的不透明像素，减少框到背景和重叠。
  • 「📊 检查覆盖」显示覆盖率、重叠像素和空部件；开发时优先把覆盖率调到 80%+，再进入摆姿势。
  • 「↕ 推荐层级」按 body → legs → arms → head → weapon 排列，符合切片叠放与外层部件覆盖内层部件的逻辑。
  • 选择模式：拖顶点(小方块)改轮廓；拖锚点(十字)改关节；拖部件内部 = 切割画面并整体移动像素 (松手即烘焙，Esc 取消)；Delete 键删除选中顶点。
  • 加点模式：点画布连续描点 → 「🔒 闭合部件」；框选模式：拖框直接切割矩形部件。
  • 新建/框选部件后自动弹出改名输入框，可在部件列表点名字随时改名。
  • 摆姿势模式：拖部件旋转、拖锚点平移 (源位置像素会被切割)；「📌 保存姿势为帧」烘焙成动画帧。
  • 「导出部件 PNG/ZIP」按框导出：框内像素保留、框外透明。
  • 「⧉ 复制当前部件」可快速做左右肢体/武器副本；「💾 拆分 JSON / 📥 导入 JSON」用于备份和复用部件轮廓、锚点、颜色。
  • 拆分几何编辑也支持 Ctrl+Z / Ctrl+Y：新建/删除部件、删点、拖顶点、改锚点、姿势平移/旋转、导入 JSON 都可回退。
☁️ 云端 / ComfyUI 生图
  • 云端/API 生图：选择 OpenAI 兼容后端时，在「🔧 AI 接口配置」填生图 Base/Key/生图模型；「AI 识图写提示词」用文本模型看图写 prompt。
  • 本地 ComfyUI 生图：在生图后端选择「本地 ComfyUI 自动生图」，填写地址并粘贴 API Format workflow JSON；工具会自动写入 prompt、negative、seed、尺寸并读取 SaveImage 输出。
  • ComfyUI 参考图模式会把当前处理图上传到 LoadImage 节点；如果浏览器连接失败，检查 ComfyUI 是否启动、地址是否正确，以及是否需要启用 CORS。
  • 固定种子 + 相同 prompt 可保持多帧角色一致；ComfyUI 模式下建议 workflow 使用同一模型、同一 LoRA/ControlNet 配置。
🎨 画布模式
  • 左键绘制 · 中键拖拽平移 · 滚轮缩放 · Ctrl+Z 撤销 / Ctrl+Y 重做；底部状态栏实时显示坐标/颜色/缩放/帧号。
  • 画布尺寸支持 16~1024 (修改会清空帧)。
  • 「💾 保存状态 / ↩ 还原保存点」：画布操作面板可保存当前全部帧，任意修改后可一键还原（含帧内容、画布尺寸、当前帧）。
  • 快捷键：P 铅笔 · E 橡皮 · G 填充 · I 取色 · L 直线 · R 矩形 · O 椭圆 · M 矩形选区 · W 魔术棒 · V 移动选区内容 · 1-9 选调色板色 · [ / ] 调笔刷大小 · Ctrl+D / Esc 取消选区 · 空格+拖拽平移视图 · Alt+点击临时取色。
  • 帧快捷键：PageUp / , 上一帧，PageDown / . 下一帧；Alt+方向键把当前帧像素整体移动 1px。
🖌 绘制工具
  • 笔刷 1/2/3px 可调；直线/矩形/椭圆支持「像素完美」防阶梯重叠。
  • 矩形/椭圆可在「□ 描边 / ■ 填充」间切换（选中矩形或椭圆工具时显示）。
  • 「⇋ 水平对称 / ⇅ 垂直对称」：开启后左右/上下镜像绘制，画布上显示粉色参考轴。
🔲 选区系统
  • 三种工具分工：M 矩形负责规整框选，🪝 套索负责自由轮廓，W 魔术棒按颜色连通区域选择；它们都会生成同一套选区遮罩。
  • 创建选区后会自动切到 ✋ 移动工具，可直接拖动选区内容；移动时遮罩边框会跟随内容移动，松手后保留新选区位置。
  • 魔术棒容差可在选区面板调节，值越大选到的相近颜色越多。
  • 选区操作支持不规则遮罩：套索/魔术棒选区也可「🎨 填充选区 / 🧹 清除选区 / 📋 复制」，「📌 粘贴为新帧」跨帧使用。
  • 可用「🚫 取消选区」、Ctrl+D 或 Esc 取消选区。
🎨 调色板系统
  • 预设：DB16 / PICO-8 / Sweetie-16 / NES / Game Boy 一键应用。
  • 导入 5 格式：.gpl / .pal / .hex / .txt / .png（自动提取不透明色）；📤 导出 .gpl。
  • 点色块选色 · 右键删除 · 双击改色 ·「＋ 追加当前色」；「🎨 提取帧色」从当前帧自动收集颜色到调色板。
🔁 Remap 统一色板
  • 把当前帧/全部帧的像素映射到调色板最近色（加权 RGB 距离），统一 AI 素材风格，透明保持。
  • 「Floyd-Steinberg 抖动」：照片转像素建议开启，过渡更自然。
🌀 变换 & 特效
  • 旋转 90°/180°、水平/垂直翻转、「✂ 边框裁剪」（内容贴左上），均可撤销。
  • 「↑↓←→ / 居中」用于当前帧像素级微调；「🎯 全部帧居中」批量稳定动画位置，适合处理 AI/GIF 导入后的抖动。
  • 特效：反相 / 灰度 / 轮廓描边（描边色=当前色）/ 替换颜色（源→目标，加权容差）/ 亮度 / 对比度。
⏱ 时间轴 & GIF
  • 帧缩略图可拖拽排序（撤销历史同步移动）；「⧉ 复制」复制当前帧，「🗑 删除」删除帧。
  • 「↕ 反转顺序」快速倒放整段动画；「⇄ 补往返帧」自动追加中间反向帧，做呼吸/摆动循环更快。
  • 洋葱皮支持前 1/2/3 帧叠加参考；「往返播放」ping-pong 模式自动倒放。
  • 「🎞️ 导出 GIF」：GIF89a + LZW 压缩，透明背景、按 FPS 循环播放；「📦 导出精灵图 PNG / 🗜️ ZIP」导出序列帧。
